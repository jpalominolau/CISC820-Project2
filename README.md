# Optimization Algorithms

This repository contains pre-compiled binaries for Numerical Optimization algorithms (Gradient Descent, Newton's Method, and BFGS).

## Requirements

* Any Unix-based terminal (macOS or Linux).
* **No C++ compiler or setup required** — pre-compiled executables are included in the repository.

## How to Run

Navigate to the root directory of the repository and execute any of the three programs:

```bash
./fun1
./fun2
./fun3
