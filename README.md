# Optimization Algorithms

This repository contains pre-compiled Linux binaries for Numerical Optimization algorithms (Gradient Descent, Newton's Method, and BFGS).

## Requirements

- Linux or Windows Subsystem for Linux (WSL).
- **Gnuplot** (required to automatically generate the convergence plots):
  - Install via terminal: `sudo apt install gnuplot`
- **No C++ compiler or setup required** — pre-compiled executables are included in the repository.

## How to Run

Navigate to the root directory of the repository in your Linux/WSL terminal and execute any of the three programs:

```bash
./fun1
./fun2
./fun3
